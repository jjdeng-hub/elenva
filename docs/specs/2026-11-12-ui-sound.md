# UI 音效：让长任务有"耳朵能听见的进度"

日期：2026-11-12 ｜ 决策：Tom ｜ 实施：Elen

## 为什么做

ELENVA 里一轮任务经常跑 30 秒到几分钟。现在只有视觉信号（转圈、状态点），
人一旦切到别的窗口就完全失去进度感，只能反复回来看。声音是最省注意力的通道：
一声"完了"顶十次 refetch。

但声音做不好比没有更糟。**原则：只在状态真正变化时响，一次交互最多一声，可关。**

## 选型（已调研，直接用）

**`uisfx@0.4.0`** — https://github.com/romainsimon/uisfx

- 代码 MIT / 音频 CC0 / 音色包美术 CC0，商用无风险
- **零运行时依赖**，压缩后 12 kB，Web Audio 本地合成（不逐条请求音频文件）
- 78 个语义 cue（`success` / `error` / `notification` / `processing` …），12 套音色
- 有 6 个 loop cue（`processing` / `connecting` / `loading` …），正好对应"任务在跑"
- 自带 8 声道、重复抑制、冷却、loop 去重；`setEnabled` / `setVolume` / `preferences` 可直接持久化

不选的理由（都查过了，别再回头挑）：

- `use-sound`：只是 Howler 的 hook（337k 周下载），**音频要自己找**，版权和音色统一都得自己做
- `soundcn`：700+ 音效，但**许可证缺失（license: null）**，商用不敢用
- `snd-lib`：资源包不错，但 2022 年后没更新，没有 loop 语义
- `ZzFX`：合成器，游戏味太重，做产品 UI 不合适

## 事件 → cue 映射（这一版只做这八条）

| 事件 | cue | 规则 |
| --- | --- | --- |
| 指令真正提交（Enter / 发送键） | `send` | 只在提交后响；不要叠 `press` |
| 一轮跑完（成功） | `complete` | **短任务（< 2s）不响**——快速问答不该出声 |
| 一轮失败 | `error` | 与 `complete` 互斥 |
| 出现待审批 | `notification` | 只在 pending 集合 空→非空 时响一次；60s 未被处理可再 `warning` 一次（可关） |
| 批准 / 拒绝 | `check` / `cancel` | 跟着用户点击走，不跟 SSE |
| 连接断开 | `disconnect` | 一次；恢复时 `connect` |
| 长任务运行中 | `processing` loop | 仅当本轮已跑 > 15s 才起 loop，音量 0.35；结束/失败/取消**必须 stop** |
| 切换会话 / 模型 | `select` | 轻，可被冷却抑制 |

不要做的事：hover 音、每个工具调用都响、批量列表滚动响、页面加载响。

## 音量与环境

- 默认 `minimal` 音色，音量 **0.6**；loop 默认关（设置里单独开）
- **标签页不可见时**音量 ×1.0，可见时 ×0.55 —— 切走了才需要叫住人，盯着屏幕时别吵
- 三档偏好：`静音` / `轻`（0.35）/ `标准`（0.6），存在 `localStorage` 的 `elenva:sound`
- `prefers-reduced-motion` **不等于**静音，不要拿它代替用户的声音偏好

## 技术约束

1. **SSR 安全**：`uisfx` 只能在客户端实例化。用 `"use client"` + 动态 `import()`，模块级单例
2. **必须 `unlock()`**：浏览器要求首次手势后才能出声。在第一次 `pointerdown`/`keydown` 上解锁（`{ capture: true, once: true }`），解锁前**不要排队播放**，直接丢弃（避免延迟炸出一串旧音）
3. 写一个 `lib/sound.ts` 单例 + `useSound()` 钩子；**不要**在每个组件里 `createUISFX`
4. 事件来源统一：Pi 走 `useAgentSession`，Hermes 走 `useAcpSession`，两边都接到同一套 cue 上（P2 已经把两者收在 `SessionRuntimeSurface` 里）
5. 循环必须 `finally { loop?.stop() }`；SSE 断了也要 stop
6. 响度与去重交给库的冷却参数，不要自己再写定时器

## 界面

- **设置页**加「声音」一节：开关 + 三档音量 + 音色选择（`minimal` / `studio` / `scifi` / `soft`），带试听按钮
- 会话页 composer 右侧放一个小喇叭图标（静音切换），`data-testid="sound-toggle"`
- 不要在主界面常驻音量滑杆

## 验收（要贴实测）

1. 发一条短指令（模型 2s 内回）→ **不出声**
2. 跑一条 > 15s 的任务 → 15s 起有 loop；结束时 loop 立即停 + 一声 `complete`
3. 制造一次失败（模型 id 非法）→ `error`
4. 触发一次审批 → `notification` 只响一次；批准后 `check`
5. 停掉 `elenva-acp` → `disconnect` 一声；恢复 → `connect`
6. 设置里静音 → 上述全部无声，刷新后仍静音
7. `npx tsc --noEmit` 通过；`npm run build` 通过（SSR 不炸）
8. 页面上给出 `data-testid="sound-toggle"` 与 `data-sound-state`（`on|off`）供自动化断言
